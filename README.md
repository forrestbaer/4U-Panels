# 4U-Panels

I use these to create front-panel layouts for [Loudest Warning](https://loudestwarning.tumblr.com/LW%20FORMAT) and Serge style (6 hole and 8 hole spacing) instruments. Included are hole spacing guides, LW panels and Bud-Box layouts as well as visual components for banana jacks, switches, leds and potentiometers.

Feel free to use these as you see fit, enjoy!
